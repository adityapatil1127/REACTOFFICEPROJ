# LOOM

A small clothing storefront demo built with React and Vite. It uses local mock product data and CSS effects to make common shopping moments feel responsive: filtering skeletons, image loading placeholders, animated favorites, add-to-cart feedback, product details, and a slide-in cart.

## Run locally

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.

Run `npm run build` to create a production build. This demo has no backend, database, authentication, or payment processing. Product photography is loaded from Unsplash.

## Customize

- Edit the mock catalog in `src/data/products.js`.
- Replace `Your Name` in `src/components/SubmittedBy.jsx`.
